# 📚 Library Management System - SQL Project

> End-to-end Library Management Analysis using PostgreSQL - 18 Business Problems Solved

## 📖 Overview
This project analyzes a library management system to manage books, members, employees, and issued records. It solves real-world business problems like identifying overdue books, high-risk members, and branch performance.

## 🗄️ Database Schema
- `branch` - Branch details
- `employees` - Employee details
- `members` - Library members
- `books` - Books inventory
- `issued_status` - Books issued records
- `return_status` - Books returned records

## 🎯 Business Tasks Solved (18 Queries)
- Task 17: Identify Members Issuing High-Risk Books (damaged > 2 times)
- Task 18: Branch performance report
- Overdue books, rental income, employee performance etc.
Full queries in `library_project.sql`
